Mission Overview

This laboratory activity is part of the onboarding process as a Junior Cloud Infrastructure Engineer Trainee, focused on learning Linux, documentation, and GitHub version control.

Objectives
Access a cloud-based Linux environment using KillerCoda
Explore and navigate the Linux operating system
Gather basic system information
Organize files and directories using Linux commands
Create and maintain a professional GitHub repository
Document technical work using Markdown

Activities Performed
Launched an Ubuntu 24.04 Linux Playground on KillerCoda
Created a new user account with sudo access
Gathered system information (distro, kernel, CPU, memory, disk space)
Created folder structure (Notes, Reports, Screenshots)
Created about-me.md inside the Notes folder
Created and organized a GitHub repository

Skills Learned

Learned how to navigate the Linux terminal, manage users, gather system information, and organize a professional GitHub portfolio.
